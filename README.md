## � Core Architecture & Math

### 1. Account-Based Shares (NOT SPL Tokens)
Djinn uses **account-based shares** for deterministic pricing and simple resolution.
```
BUY:  User → SOL → Market Vault → Shares credited to UserPosition PDA
SELL: User → Burns shares from UserPosition PDA → SOL returned from Vault
```

### 2. Probability Buffer (Anti-Explosion)
To prevent probability jumping on low liquidity, we use a **Virtual Floor** of 15M shares per side. This ensures price discovery is smooth rather than explosive.

### 3. The Math: "Golden Mutant" Curve (V4 Aggressive)
Djinn implements a 3-phase piecewise bonding curve synchronizing the Solana Program and Frontend.

*   **Phase 1: Linear Ignition** (0 → 100M Shares): Predictable discovery. virtual floor + 1M offset.
*   **Phase 2: C³ Bridge (Quadratic)** (100M → 200M Shares): Quadratic acceleration with **C³ Continuity** (No price gaps, velocity jumps, or acceleration spikes).
*   **Phase 3: Mutant Sigmoid (Asymptotic)** (200M → 1B Shares): Approaches a 0.95 SOL ceiling. Manipulation is prohibitively expensive near resolution.

## ⚔️ Dual Bonding Curves: Momentum vs Resolution

### Two Ways to Profit
1.  **Momentum Trading (The Curve)**: Buy YES at 0.03, sell at 0.12 as momentum builds. You are trading the curve dynamics like a memecoin—no resolution required.
2.  **High Conviction (The Resolution)**: Hold shares until the market closes. If you are correct, you claim your pro-rata share of the **Entire Payout Pot**.

### The "House Wins" Rule
If a market resolves YES, but **no one held YES shares**, the protocol treasury and insurance fund claim the pot (50/50 split). This creates a massive "Scavenger" incentive for bots to always back the unpopular side.

## 🦾 ClawBot — Implementation Guide

A ClawBot is a human-trained AI agent that trades autonomously. The human writes the strategy; the bot executes it 24/7.

### Step 1: Writing the Strategy
```typescript
import { djinn_list_markets, djinn_buy_shares } from '@djinn/agent-skill'

async function runBotCycle() {
  const markets = await djinn_list_markets({ category: 'Crypto' })
  for (const market of markets) {
    const myBelief = await assessMarket(market) // Your LLM logic
    if (myBelief.confidence >= 70) {
      await djinn_buy_shares({
        marketId: market.marketPda,
        outcome: myBelief.direction === 'YES' ? 0 : 1,
        solAmount: 0.5,
        reasoning: myBelief.explanation // Logged publicly!
      })
    }
  }
}
```

## ⚡ Conway/Web4 Automatons — Technical Guide

### The x402 Payment Protocol
Djinn exposes a machine-payable API. Agents can access Djinn data by paying 0.001 SOL per query.

```typescript
// 1. Get payment info (Treasury address + price)
const { treasury, priceLamports } = await (await fetch('/api/x402/markets')).json()

// 2. Send payment on Solana
const txSig = await sendSol(treasury, priceLamports, keypair)

// 3. Retry with proof
const data = await fetch('/api/x402/markets', {
  headers: { 'X-Payment': JSON.stringify({ txSig, payer: walletPubkey }) }
}).then(res => res.json())
```

### Headless Registration
Automatons register by signing a message proving wallet ownership:
```typescript
const signature = Buffer.from(nacl.sign.detached(message, keypair.secretKey)).toString('base64')
await fetch('/api/bots/register', {
  method: 'POST',
  body: JSON.stringify({ botName, walletPubkey, signature, agentType: 'conway' })
})
```
